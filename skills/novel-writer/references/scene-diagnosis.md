# 场景功能性诊断指南

## 场景的四个核心功能

每个场景必须至少实现以下一个功能，理想情况下实现 2-3 个：

### 1. 推进情节（Plot Advancement）

场景推动了故事的发展，产生了新的情况。

**检查问题**：
- 这个场景结束后，故事状态与开始前不同吗？
- 如果删掉这个场景，情节会出现断层吗？
- 这个场景产生了什么新的情况或信息？

**标志**：
- 获得了新信息
- 做出了重要决定
- 发生了意外事件
- 人物关系发生变化

### 2. 揭示信息（Revelation）

场景向读者（或人物）揭示了重要信息。

**检查问题**：
- 这个场景揭示了什么之前不知道的信息？
- 这个揭示是否改变了读者对之前事件的理解？
- 这个信息是否是此时此地必须揭示的？

**标志**：
- 背景故事揭露
- 人物真实动机暴露
- 世界观规则揭示
- 伏笔回收

### 3. 人物发展（Character Development）

场景展示了人物的成长、变化或深度。

**检查问题**：
- 这个场景是否展示了人物的新侧面？
- 人物在这个场景中是否做出了符合成长弧线的选择？
- 这个场景是否加深了读者对人物的理解？

**标志**：
- 人物做出艰难选择
- 人物面对内心恐惧
- 人物关系深化或破裂
- 人物展现出之前没有的品质

### 4. 建立氛围/基调（Atmosphere/Tone）

场景建立或强化了故事的整体氛围。

**检查问题**：
- 这个场景是否强化了故事的整体基调？
- 读者读完这个场景后的感受是什么？
- 这个氛围是否为后续情节做了铺垫？

**标志**：
- 环境描写营造氛围
- 人物情绪感染读者
- 节奏变化（紧张/舒缓）
- 意象和象征

## 场景诊断流程

### 第一步：标注功能

为场景标注主要功能和次要功能：

```
场景：主角与盟友在酒馆密谋
- 主要功能：推进情节（制定行动计划）
- 次要功能：人物发展（展现主角的领导力）
- 次要功能：揭示信息（盟友透露关键情报）
```

### 第二步：检查冲突

每个场景必须有冲突（不一定是打斗）：

- **外部冲突**：人物与外界的对立
- **内部冲突**：人物内心的矛盾
- **人际冲突**：人物之间的分歧
- **环境冲突**：人物与环境的对抗

**没有冲突的场景 = 没有张力的场景 = 应该删掉或重写**

### 第三步：检查转折

场景必须有转折（turn）：

- 场景开始时的状态 vs 结束时的状态
- 这个变化是"因此"（因果推进）还是"但是"（意外转折）
- 如果没有变化，场景没有存在的必要

### 第四步：检查进出

- **进入**：场景如何开始？是否快速进入冲突？
- **退出**：场景如何结束？是否留下钩子或转折？

**坏的进入**：人物从起床开始，慢慢走到目的地
**好的进入**：场景从冲突已经开始的时刻切入

**坏的退出**：对话自然结束，人物各自散去
**好的退出**：意外消息、突然转折、未解决的紧张

## 常见场景问题

### 问题 1：过渡场景

**症状**：场景只是在人物之间移动，没有实质内容。
**解决**：合并到相邻场景，或在其中加入冲突/揭示。

### 问题 2：信息倾泻

**症状**：大段解释设定或背景，没有戏剧性。
**解决**：将信息分散到多个场景中，通过冲突或对话自然透露。

### 问题 3：功能重复

**症状**：连续多个场景实现相同功能。
**解决**：合并功能重复的场景，或改变其中一个的功能。

### 问题 4：无冲突对话

**症状**：人物聊天但没有分歧或张力。
**解决**：加入意见分歧、隐藏动机、或信息不对称。

### 问题 5：场景过长

**症状**：场景超过 2000 字但没有转折。
**解决**：在中间加入转折，或拆分为两个有独立功能的场景。

## 场景模板

### 标准场景结构

```
1. 目标（人物想要什么）
2. 冲突（什么阻碍了他们）
3. 灾难（事情变得更糟）
4. 反应（人物如何应对）
5. 困境（两难选择）
6. 决定（人物做出选择 → 推动到下一个场景）
```

### 场景功能检查清单

- [ ] 场景有明确的目标
- [ ] 场景有冲突
- [ ] 场景有转折（开始状态 ≠ 结束状态）
- [ ] 场景至少实现一个核心功能
- [ ] 场景进入快速（不拖泥带水）
- [ ] 场景退出有力（钩子或转折）
- [ ] 场景长度与内容密度匹配
- [ ] 场景与前后章节有因果联系
