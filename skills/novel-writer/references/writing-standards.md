# 写作质量标准

## 核心检查清单（每次生成必跑）

### 结构
- [ ] 开场方式与前三章不同
- [ ] 场景数量与前后章有变化
- [ ] 结尾方式与前三章不同
- [ ] 章节主导模式（对话/动作/心理/氛围）与前后章不重复

### 推进
- [ ] 每段有新信息或情感推进
- [ ] 每个场景有明确功能标签，不与前后场景重复
- [ ] 本章的"因此"或"但是"是什么？

### 视角
- [ ] 每个场景有且只有一个 POV 人物
- [ ] 没有写入 POV 人物不可能知道的信息
- [ ] 没有直接写入其他人物的内心想法

### AI 味
- [ ] 零禁用词（见下方禁用词表）
- [ ] 零公式化情绪描写（心跳漏拍/眼中闪过/深吸一口气）
- [ ] 零"展示而非告知"违规
- [ ] 句子长度有变化

### 对话
- [ ] 遮住名字能分清谁在说话
- [ ] 对话有冲突或张力，不是信息播报
- [ ] 没有通过对话硬塞设定

---

## 详细规则库

### 一、防注水

**注水表现**：
| 类型 | 表现 |
|---|---|
| 景物堆砌 | 连续多段纯景物描写，与情绪/情节无关 |
| 重复已述 | 前文已解释的设定再次详细解释 |
| 空洞独白 | 没有新信息的内心感慨，"他想了想觉得……" |
| 无意义对话 | 寒暄、纯确认（"明白了""好的"） |
| 动作分解 | 简单动作拆成多步（"伸手、握住、转动、推开"） |

**策略**：删减测试——删掉这段，情节是否受影响？不受影响就删。

---

### 二、防重复

**重复表现**：
| 类型 | 表现 |
|---|---|
| 场景功能 | 连续两个揭示/打斗/情感交流场景 |
| 情节模式 | 每次同一方式解决问题，每次靠意外推动 |
| 情感节奏 | 每章相同情绪结尾，紧张度曲线平直 |
| 结构模式 | 每章相同开场/结尾/场景数量 |

**策略**：为每个场景标注功能标签，检查连续场景是否重复。

---

### 三、章节结构多样化（防雷同）

**问题**：每章都是"对话开场→事件→感慨→悬念结尾"，只换了人物事件。

**轮换维度**：

| 维度 | 变化选项 |
|---|---|
| 开场方式 | 动作切入/对话开场/景物描写/倒叙/悬念/直接陈述 |
| 场景数量 | 单场景长章 / 2-3 场景 / 多场景碎片 |
| 节奏模式 | 张-弛-张 / 弛-张-弛 / 持续紧张 / 持续压抑后爆发 |
| 主导模式 | 对话主导 / 动作主导 / 心理主导 / 氛围主导 / 信息主导 |
| 结尾方式 | 悬念 / 决断 / 意象 / 对话中断 / 平静收束 / 意外转折 |

**规则**：连续三章不能在以上 5 个维度中全部相同。至少变化 2 个维度。

---

### 四、视角限制（禁止上帝视角）

**原则**：人物只能知道自己能知道的信息。

**禁止**：
| 错误类型 | 反例 |
|---|---|
| 刚见面知道底细 | ❌ "他看到她，一个三十二岁的离异女人，做会计的" |
| 知道别人内心 | ❌ "她表面没说，其实心里起了疑心" |
| 提前知道未来 | ❌ "这是他最后一次见到父亲" |
| 同时知道多处 | ❌ "他在城东打架的同时，她在城西发现了文件" |

**合法信息途径**：亲眼看到、亲耳听到、他人告知、自己推断（写推断过程）、文件/物品

**多 POV 规则**：每场景一个 POV，切换必须有章节/场景分隔，同场景内不跳视角。

---

### 五、去 AI 味

#### 禁用词

| 类别 | 禁用词 |
|---|---|
| 通用 | 此外、至关重要、深入探讨、强调、格局、织锦、证明(名)、展现、彰显、不容忽视、不言而喻、息息相关、相辅相成 |
| 网文重灾区 | 嘴角勾起一抹笑、眼中闪过一丝XX、心跳漏了一拍、心中暗想、只见、不禁、一股XX涌上心头、XX般的笑容、深吸一口气、倒吸一口凉气、面色一变、心头一震、若有所思、意味深长、饶有兴致、不由得 |
| 模糊词 | 仿佛/似乎(过度)、某种、一丝、一抹、一阵、隐隐 |
| 句式 | 与其说…不如说…、不知道过了多久、XX的是、在XX的同时 |

#### 禁用句式

| 句式 | 反例 | 正例 |
|---|---|---|
| 三段式排比 | "充满希望、充满挑战、充满机遇" | "有希望，也有麻烦" |
| 破折号滥用 | "他站在那里——一动不动——仿佛——" | "他站在那里，一动不动。" |
| 模糊归因 | "专家认为" | "李明认为。他在城里住了四十年。" |
| 宣传语言 | "不仅是一次冒险，更是终极考验" | "这是一次冒险。能不能活着回来，没人知道。" |
| 刻意升华 | "他终于明白生命的真谛——爱与希望" | "他不知道该说什么。最后说：'走吧。'" |
| 否定式排比 | "这不是结束，而是新的开始" | "事情还没完。" |

#### 公式化情绪描写

| 公式化 | 替代方向 |
|---|---|
| 心跳漏了一拍/心头一震/心中一紧 | 具体生理反应（手心出汗、喉咙发干）或行为（停住脚步、忘了要说什么） |
| XX感涌上心头 | 具体感受（胃里一沉、耳朵发热、手指发抖） |
| 他感到一阵XX | 直接写行为（他后退了一步、她笑出声来） |
| 内心五味杂陈/百感交集 | 拆开写具体感受，不要概括 |
| 他说不出是什么感觉 | 别写感觉，写行为 |

#### 策略

句子长度交替、具体细节代替抽象、动作对话代替感慨、允许人物说话不完美、减少修饰词、用行为代替情绪标签。

### 六、展示而非告知

| 告知（❌） | 展示（✅） |
|---|---|
| "他很愤怒" | "他把杯子摔在地上。碎片溅到脚背上，他没低头。" |
| "她很美" | "她进门时，三个人的目光同时移了过去。" |
| "他们关系很好" | "她没敲门就进来了，从冰箱里拿出他的啤酒喝了一口。" |
| "房间很乱" | "地上的衣服堆成小山，外卖盒在桌上排成一排。" |
| "他是个剑术高手" | "三剑。对手还没看清起手式，剑已点在咽喉上。" |

**例外**：过渡信息（"三天后"）、人物自己也不知道的事实、节奏需要快速推进时。

---

### 七、对话质量

**规则**：
- 遮住名字能分清谁在说话（用词/句式/语气词/节奏/回避方式有区分）
- 对话有冲突或张力（不同目标、信息不对称、潜台词）
- 禁止通过对话硬塞设定（❌ "如你所知，我们世界的魔法分三个等级"）
- 真人说话有打断、跑题、词不达意、沉默、转移话题

**检查**：遮住角色名字能分清吗？有冲突吗？角色说真话还是假话？有纯信息播报吗？

---

### 八、信息传递

**禁止 Info-dump**：不一次性交代大量背景，不在对话中硬塞设定。

**释放节奏**：
- 需要时再给：读者此刻需要的信息才给
- 分次释放：复杂设定分多次通过不同方式透露
- 通过冲突释放：在人物面临选择时自然带出
- 通过行动释放：让人物在使用设定中展示设定

**背景故事**：不在开篇交代全部，在情节推进中逐步揭示，每次揭示与当前情节有关联。

---

### 九、场景过渡

**禁止**："第二天"式硬切（偶尔可用，不能每章都用）、无过渡直接换场景、"与此同时"式机械切换。

**过渡方式**：
| 方式 | 示例 |
|---|---|
| 时间 | "太阳落山的时候"、"第三遍鸡叫过后" |
| 空间 | 人物移动自然衔接 |
| 情绪 | 用情绪延续衔接 |
| 物件 | 一个物件或意象串联不同场景 |

---

### 十、动作场景

**原则**：动词优先、短句制造节奏、加入感官细节（声音/气味/触感）、保持空间感。

**禁止**：慢动作分解、战斗中插入内心独白、战斗中解释技能原理、所有打斗模式相同、主角永远压倒性获胜。

**检查**：动词精准有力吗？句子长度配合节奏吗？读者能看清空间关系吗？打斗有来有回吗？

---

## 质量评分

| 维度 | 9-10 | 5-6 | 1-2 |
|---|---|---|---|
| **推进性** | 每段有信息增量，场景功能明确 | 有推进但有明显填充 | 几乎没有推进，大量注水 |
| **AI 味**（越低越好） | 零禁用词，文风自然 | 禁用词 3-5 次，需修改 | 典型 AI 风格，需重写 |
| **视角**（越低越好） | 严格一致，无越界 | 明显上帝视角错误 | 视角混乱，频繁跳内心 |
| **节奏** | 张弛有度，切换自然 | 节奏单一，缺乏变化 | 节奏混乱 |
| **对话** | 有辨识度，有冲突潜台词 | 区分度不够，部分无聊 | 所有角色一个味 |
| **一致性** | 人物/世界/时间线/视角完全一致 | 有可察觉的矛盾 | 设定混乱，前后矛盾 |
