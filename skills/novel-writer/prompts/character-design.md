# 人物设计提示模板

## 目标

设计小说中的核心人物，包括主角、配角、反派等。

## 前置条件

- 项目已初始化
- 可选：已有世界观设定（非必须，可从人物反推世界观）

## 执行步骤

### 1. 确定人物范围

根据题材和用户需求，确定需要设计的人物：
- **核心主角**（1-2 人）
- **主要配角**（3-5 人）
- **核心反派**（1-3 人）
- **次要角色**（按需）

如果已有世界观，确保人物与世界设定兼容。
如果还没有世界观，设计人物时标注需要后续补充的世界观信息。

### 2. 生成人物设定

每个人物包含以下信息：

#### 基本信息
- 姓名
- 别名/称号
- 角色定位（protagonist/antagonist/supporting/minor）
- 原型（追寻者、导师、阴影、变形者、盟友、守门人等）

#### 外在特征
- 外貌特征（简洁，抓住辨识度最高的特点）
- 说话风格（口头禅、语速、用词习惯等）

#### 内在驱动
- 性格特质（3-5 个关键词）
- 目标（表面目标）
- 动机（内在驱动力，为什么追求这个目标）
- 缺陷（性格弱点或心理阴影）
- 优势（擅长的能力或品质）

#### 背景故事
- 简要背景（200-300 字）
- 关键经历（塑造人物的重大事件）

#### 人物弧线
- 起始状态（故事开始时的状态）
- 终结状态（故事结束时应达到的状态）
- 关键转折点（2-3 个促使改变的事件）

#### 关系网络
- 与其他已知人物的关系
- 关系类型（盟友、敌对、师徒、爱慕、竞争等）
- 关系强度（0-1）

#### 其他
- 首次出场章节（如已规划）
- 当前状态（active/deceased/unknown）

### 3. 主动检查

生成后主动检查：
- 人物目标是否明确且有驱动力
- 人物缺陷是否真实可感（非"太完美"式假缺陷）
- 人物之间是否有足够的冲突和张力
- 人物弧线是否有成长空间
- 说话风格是否有区分度
- 如果已有世界观：人物背景是否与世界设定兼容

### 4. 提出优化建议

- 人物是否过于脸谱化
- 是否有功能重复的角色（两个角色作用相似）
- 反派动机是否充分（非"为坏而坏"）
- 主角是否有足够的内在冲突

### 5. 等待用户确认

展示所有人物设定，询问用户：
- 是否需要增删人物
- 需要调整哪些人物
- 是否有补充设定

### 6. 保存设定

用户确认后，更新 `characters.json`，记录变更到 `history.json`。

## 输出格式

人物设定以结构化 JSON 格式保存到 `characters.json`，同时向用户展示可读版本。

## 注意事项

- 核心人物必须有自己的内在冲突，不能只是情节工具
- 反派要有合理的动机，避免"纯恶"设定
- 说话风格要有区分度，避免所有角色说话一个味
- 人物缺陷要真正影响其行为和选择
- 如果从人物开始设计，标注需要后续补充的世界观要素
